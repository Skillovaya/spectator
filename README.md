# Спектатор — свободная камера для «Танков Онлайн»

Один локальный userscript для **браузерной HTML5-версии** игры. Камера отвязывается от танка и летает по карте; сам танк остаётся в бою. Это **не официальный режим спектатора**: скрипт не выдаёт доступ к закрытым боям, не скрывает танк от других игроков и не изменяет данные на сервере.

## Установка

1. Установите менеджер userscript-скриптов, например Tampermonkey.
2. Создайте новый скрипт, вставьте содержимое [`spectator.user.js`](spectator.user.js) целиком и сохраните. Внешние библиотеки не нужны.
3. Откройте [игру в браузере](https://tankionline.com/play/), войдите в бой и нажмите **F8** или кнопку «Открепить камеру» в правом верхнем углу. Нажмите **F8** ещё раз, **Esc** или кнопку «Вернуть камеру», чтобы вернуться к обычной камере.

Перед включением отпустите клавиши управления танком. Если версия клиента не совпадает с ожидаемой, скрипт покажет код ошибки и не оставит камеру изменённой.

## Если камера не открепляется

1. **Обновите установленный скрипт до версии 0.3.0:** замените его содержимое кодом из [`spectator.user.js`](spectator.user.js), сохраните в Tampermonkey и **перезагрузите вкладку игры**. После обновления в панели должна быть кнопка «Показать диагностику». Версию можно сверить в начале скопированного лога.
2. Войдите в бой и снова нажмите «Открепить камеру». Красный статус теперь содержит код и конкретный этап ошибки.
3. Нажмите **«Показать диагностику» → «Скопировать лог»** и пришлите код ошибки и скопированный текст. Если браузер не разрешил копирование, текст выделится в поле: нажмите `Ctrl+C` вручную.
4. Перед отправкой **просмотрите лог**: в него специально не добавляются координаты, ники, куки и сетевые пакеты, но сообщения об ошибках стороннего клиента могут содержать неожиданную информацию. Скрипт не отправляет лог по сети: он хранится в памяти вкладки и выводится также в консоль браузера с префиксом `[Spectator 0.3.0]`.

Версия 0.3.0 проверяет React-маркеры не только на `#root`, но и на `canvas`, его предках, ближайших DOM-контейнерах и ограниченном числе потомков. Инъекция запрашивается в контексте страницы (`@sandbox raw` / `@inject-into page`). Если ошибка `REACT_ROOT_MISSING` осталась, поле `trace.react.markers` покажет количество видимых привязок; нули **не доказывают**, что причина именно в изоляции скрипта: клиент игры мог измениться или привязка находится за пределами области поиска. Если маркеры видны, но появляется `STORE_NOT_FOUND`, нужен новый лог для проверки структуры Fiber. Работа версии 0.3.0 в живой игре пока не подтверждена.

| Код | На каком этапе проблема |
| --- | --- |
| `KEYS_HELD` | Отпустите клавиши управления танком перед включением |
| `ROOT_MISSING` / `REACT_ROOT_MISSING` / `STORE_NOT_FOUND` | Нет `#root` и canvas / не видны React-маркеры или Fiber недоступен / Fiber найден, но store не найден |
| `BATTLE_NOT_READY` / `BATTLE_STATE_ERROR` / `LOCAL_TANK_NOT_FOUND` | Бой ещё не загрузился или не найден локальный танк |
| `CAMERA_NOT_FOUND` / `CAMERA_INCOMPATIBLE` | В компонентах танка нет ожидаемой камеры или изменились её поля |
| `PROBE_EXCEPTION` / `ATTACH_FAILED` / `CAMERA_SYNC_FAILED` | Ошибка поиска, подключения или обновления камеры; подробности в логе |

Диагностика на красном статусе **остаётся видимой**, пока причина не изменится; опрос игры не стирает сообщение об ошибке. Без лога невозможно надёжно исправить несовместимость с конкретной сборкой игры.

## Управление

| Клавиши | Действие |
| --- | --- |
| `F8` | Включить или выключить свободную камеру |
| `W A S D` | Лететь относительно направления камеры |
| `Q` / `E` | Вниз / вверх |
| Зажать правую кнопку мыши и двигать мышь | Осмотреться; по возможности включается захват курсора |
| Стрелки | Поворот камеры без мыши |
| `Shift` / `Ctrl` | Ускориться / замедлиться, пока клавиша удерживается |
| Колесо мыши | Изменить базовую скорость |
| `Esc` | Выключить свободную камеру |

Клавиши перемещения перехватываются во время полёта, чтобы не управлять танком. При выключении, выходе из боя или смене камеры скрипт возвращает исходные методы и настройки камеры. Если нужно немедленно сбросить состояние клиента, перезагрузите страницу.

## Ограничения

- Поддерживается только страница `tankionline.com/play*` и её поддомены; настольный клиент и мобильное приложение userscript не запускают.
- Скрипт опирается на **внутренние поля** `FollowCamera` браузерного клиента. Игра обновляется: если эти поля изменятся, потребуется адаптировать скрипт. Проверки в репозитории используют модель камеры, **не живой сервер игры**; работа с текущей сборкой игры здесь не подтверждена.
- Танку всё ещё можно нанести урон; состояние боя и права аккаунта не меняются. Пользуйтесь скриптом только там, где это разрешено правилами игры.

## Проверка изменений

Нужен Node.js 20 или новее. Зависимости устанавливать не требуется:

```sh
npm test
npm run check
```

Тесты проверяют ограниченный поиск React-маркеров, поиск камеры, полёт, откат перехватов и безопасный отказ при несовместимой камере.
